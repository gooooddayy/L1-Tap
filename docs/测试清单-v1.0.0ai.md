# L1Tap v1.0.0ai 真机测试清单（2026-10-13）

> 本版为触摸停止架构重构：删除 ACTION_OUTSIDE 旁听通道，改为「海绵层」——执行期全屏触摸覆盖、
> 仅锁点 ±2dp 小孔，**孔外摸到即停（DOWN 即停，不必抬手）**；另修复首击自伤（首击延迟 120ms）。
> 建议参数：连点时间 10 秒 / 频次 50 次 / 轮次 0（5Hz）。测前开启无障碍「L1Tap 自动点击服务」。
> 已装机：1.0.0ai（vc14）。日志我这边可代抓：`adb logcat | grep -E "AutoClicker|TapService"`

## 已知边界（不算 bug）

- **靶标正中心 ±7px**（指甲尖大小）：穿透给应用、不触发停止——自动点击必经此孔，物理不可区分；稍偏就停。
- **停止的那一下触摸被"海绵"吸收**、不传给下面的应用——防误触设计；想继续操作再摸一次即可。
- 侧滑开始瞬间**在途的那一击**可能先完成（≤1 次、固定落靶点）——平台边界（af 起概率已减半）。
- 状态栏最顶部下拉区域属系统窗口，摸它不停——红钮 / 通知栏兜底。
