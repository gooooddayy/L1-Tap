# L1Tap v1.0.0ae 真机测试清单（2026-10-13）

> 本版改动：① 触摸旁听彻底移除时间窗（修「点/滑概率性不停止」）② 新增环形监听层（抓靶即停+拖动换位）③ 采样 250ms。
> 建议参数：连点时间 10 秒 / 频次 50 次 / 轮次 0（5Hz）。测前开启无障碍「L1Tap 自动点击服务」。

## 已知边界（不算 bug）

- **靶标正中心 ±22dp**（约半个指甲盖）内的触摸：穿透给应用、不触发停止——这块留给自动点击通过，物理上无法区分。稍偏一点（环内）就会停。
- 个别 App 落点处只暴露全屏容器（如网易云播放页），容器**内部**内容移位检测不到——系统信息边界；但切页/切 App 仍会停。
- 抓靶拖动时那一下触摸不会传给下面的应用（被环层接管）——防误触，安全侧。
