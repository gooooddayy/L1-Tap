# L1Tap v1.0.0ad 真机测试清单（2026-10-13）

> 本版修复：高频连点下「触摸即停」集体失灵（时间豁免窗覆盖 75% 时间轴 + 手势取消信号未利用）。
> 建议参数：**连点时间 10 秒 / 频次 50 次（= 200ms 间隔，5Hz）/ 轮次 0** —— 与出问题时的参数一致。
> 测试前：开启无障碍「L1Tap 自动点击服务」（装机后默认关闭）。

## ⑤ 已知边界（不算 bug）

- **正点在落点中心 ±16dp 内**的触摸与自动点击物理上无法区分，可能不停——但位置稍偏一点就会停（①-2/1-3 验证的就是这条边界）。
- 若与 GKD 同时派发手势，可能互相取消导致停止——宁停不停，安全侧成立。
