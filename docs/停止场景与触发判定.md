# L1-Tap 停止场景与触发判定（v1.0.0ai）

> 目的：穷举「连点执行中」所有可能引发停止的场景，逐条给出触发通道与验证状态。
> 图例：✅ 已实测通过 ｜ 🆕 v1.0.0ai 新增/重构 ｜ ⚙ 已实现（未专项实测） ｜ ✓ 天然成立
> **v1.0.0ai 变更**：触摸停止从「触摸副本旁听 + 判别」重构为「海绵层几何判别」——
> 执行期 4 块可触摸矩形铺满全屏、仅锁点 ±2dp 小孔（自动点击只走小孔）；整个
> ACTION_OUTSIDE 通道已删除。全版本实测证据见 `全版本审查-触摸停止根因与重构方案.md`。

## A. 用户主动停止

| # | 场景 | 触发通道 | 状态 |
|---|---|---|---|
| A1 | 触摸屏幕任意位置（孔外） | 海绵层：摸到即停（自动点击只走小孔，摸到海绵 = 100% 用户），**DOWN 即停** | 🆕 |
| A2 | 触摸锁点附近（80dp 内，仍为孔外） | 同 A1 DOWN 即停；若继续拖动（超 slop）→ 靶标跟手换位，松手保存，下轮点新位置 | 🆕 |
| A3 | 点红钮 | DOWN 即停（执行期海绵覆盖其上，经海绵同效触发；停止后不弹设置页） | ✅ |
| A4 | 按系统返回键（三键导航） | 换页 → 页面层即停；不换页（应用消费了返回）则不停 | ⚙ |
| A5 | 侧滑返回（手势导航） | 系统输入层独占侧滑，应用收不到触摸；靠「在途注入手势被取消」通道停止（ad 实测 12/12 会话必现） | ✅ |
| A6 | 按主页 / 多任务 | 换页/回桌面 → 页面层 + 采样层（≤0.25s）；手势导航为滑动（同 A5 取消通道） | ⚙ |
| A7 | 拉通知栏点「停止」 | 通知 Action（不依赖悬浮窗/触摸/无障碍事件） | ✅ |
| A8 | 切到其它应用 / 回桌面 | 页面层包名变化 + 采样层 | ✅ |
| A9 | 从最近任务划掉 App | 进程终止，应用整体退出 | ✓ |

> 唯一盲区：**锁点正中 ±2dp（≈±7px，指甲尖大小）**——自动点击必经此孔，物理上无法与手指区分；稍偏即停。

## B. 目标 / 页面变化自动停止

| # | 场景 | 触发通道 | 状态 |
|---|---|---|---|
| B1 | 落点控件内容变化（文字 / 位置 / 尺寸） | 采样层：落点控件特征比对（每 0.25s） | ✅（网易云轮换文案实测触发过） |
| B2 | 换页后落点取不到控件（整屏视频 / 图片 / 游戏） | 采样层 sig-gone 规则：有锚但落点消失 = 变化 | ✅ |
| B3 | 返回 / 跳转换页（含弹窗、键盘、系统面板出现） | 页面层：窗口状态事件（**仅比前台包名**，同应用弹窗不误停），即时停 | ✅（ac 修正） |
| B4 | 前台应用切换 | 页面层 + 采样层包名对比（≤0.25s） | ✅ |
| B5 | 屏幕旋转 | 采样层屏幕方向对比 | ⚙ |
| B6 | 广告 / 对话框弹窗遮挡 | 页面层（新窗口事件）+ 采样层（落点被覆盖） | ⚙ |

## C. 环境 / 被动停止

| # | 场景 | 触发通道 | 状态 |
|---|---|---|---|
| C1 | 息屏（电源键 / 超时 / 低电量） | SCREEN_OFF 广播 ×2（引擎侧 + 悬浮层侧） | ⚙ |
| C2 | 来电 / 闹钟全屏 | 页面层 + 采样层 | ⚙ |
| C3 | 跑完设定轮次 | 自然完成并提示；海绵同步拆除 | ✅ |
| C4 | 连续派发失败 ≥10 次 | 熔断自动停 | ⚙ |
| C5 | 无障碍服务被关闭 | onDestroy → 停引擎 | ✓ |
| C6 | 进程被杀（ColorOS 省电 / Hans 冻结） | 整个应用退出（无法由应用阻止；被清理后重开 App 即恢复） | ✓ |
| C7 | 注入手势派发回调丢失（个别 ROM 吞回调） | 看门狗 200ms 强制解锁（防「引擎在跑但一次不点」） | ⚙ |

## D. 明确不停止（设计如此）

| # | 场景 | 说明 |
|---|---|---|
| D1 | 音量键 | 不改变屏幕内容，无害，不停 |
| D2 | 充电插拔 / 普通通知到达 | 不视为目标变化 |
| D3 | 状态栏下拉区 | 属系统窗口（在海绵之上），摸它不停——红钮 / 通知栏为兜底 |

## E. 已知取舍（诚实声明）

1. **锁点正中 ±2dp 盲区**：自动点击必经的小孔，物理不可区分；稍偏即停。
2. **停止的那一下触摸被海绵吸收**、不传给下层应用（防误触，安全侧）；想继续操作再摸一次即可。
3. **侧滑**：ColorOS 系统层独占，侧滑开始瞬间在途的那一击仍可能完成（≤1 击、固定落靶点）——v1.0.0af 起戳长 15ms 已把概率减半，无法归零（平台边界）。
4. 个别 App 落点处只暴露全屏容器（如网易云播放页），容器**内部**内容移位检测不到；切页 / 切 App 仍会停。
