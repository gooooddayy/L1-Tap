## 一、准备（约 2 分钟）

1. 打开 App「连点器」，从上往下确认三张卡的状态
2. **开启无障碍**：点「② 无障碍服务」卡的「去开启」→ 在系统页面找到 **L1-Tap 连点器** → 打开开关（可能再弹一次「允许」确认）→ 回到 App 应显示「✔ 已开启」
   - 若回来仍显示未开启：把 App 从最近任务划掉、重开一次
3. **后台运行保障**：点「③ 后台运行保障」→ 弹窗里选「允许」（加入电池白名单，减少被系统杀）
4. 点「**启动悬浮控件**」→ 屏幕上出现 ⚙ 齿轮 + ◎ 靶标两个悬浮钮
5. 打开【备忘录】或【计算器】当练习靶，把靶标拖到「点了也无害」的位置

**小贴士**：
- 点齿轮 = 打开设置页（连点时间/频次/轮次）；「开始」执行、「返回」只收起面板
- 参数想快点看到效果可用 `10秒 / 10次`（每 1 秒点 1 次）；默认 `30秒 / 10次`（每 3 秒 1 次）
- 执行中两个悬浮钮**锁定不动**（防误触设计），摸它们不会移动，而是触发停止

## 二、本次修复重点（问题①：按返回仍点击）

> 每条测完，等按钮恢复「齿轮」再测下一条。

- 预期：立即停止（提示「检测到返回/主页键，已停止」或「靶标位置已变化，已停止」，**两种都算通过**）
